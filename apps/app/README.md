# Оболочка Chunk

Tauri-приложение, в котором работает лаунчер Chunk: окно, системные команды и подключение ядра `packages/app-lib`. Интерфейс лежит в `apps/chunk`.

Запуск в режиме разработки из корня репозитория:

```bash
pnpm install
pnpm app:dev
```

Общее описание проекта — в [README](../../README.md).
